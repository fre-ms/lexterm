# Name search for "lexterm" (26 November 2026)

A collision check for the working name, and a first one for its planned sibling "lexident". It is not a
professional trademark search and no legal opinion. Names of private persons who hold or applied for marks are
left out.

## Method

- **Package names**: PyPI, npm, crates.io.
- **Domains**: DNS (NS and A) for `.com`, `.de`, `.org`, `.net`, `.eu`, `.io`, `.app`; WHOIS for `.com`.
- **Code**: GitHub repository search.
- **Web**: search for "LexTerm" with terminology and lexicography.
- **DPMAregister** (German, EU and international marks designating DE or the EU), wildcard search, with the
  control query `?meddra?` returning its known 4 hits: `?lexterm?`, `?lexiterm?`, `?lextherm?`, `?lexter`.
  The goods and services of the nearest marks were read from their register entries.
- **TMview** (all connected offices, including the USPTO): fuzzy search `lexterm`, "contains" search
  `lexterm`, fuzzy search `lextherm`. Every answer was checked to have come from the service (a new response of
  its own size), not left over from an earlier query.

## Findings

| Check | Result |
|---|---|
| Packages | `lexterm` is free on PyPI, npm and crates.io |
| Domains | `.com` registered on 8 May 2026 through a Chinese registrar, no address record (parked); `.de`, `.org`, `.net`, `.eu`, `.io`, `.app` without name servers |
| GitHub | an organisation "LexTerm" with "LexTermServer – Lexicography and Terminology Management System" (Python, last push October 2024, five stars) and an older REST server for TBX termbases (2015); a few unrelated small repositories ("Leo's Enhanced XTERM", 2013) |
| Web | three academic uses of the name, all in lexicography and terminology, none in medicine and none commercial (below) |
| DPMAregister | no mark "lexterm"; the wildcard hits are marks that contain it inside another word |
| TMview | no mark "lexterm" in any office; fuzzy search 28 entries, "contains" search 15, all of them other words (below) |

Earlier uses of the name:

- **LexTerm Manager** (Brigham Young University): a design for one data model serving lexicography and
  terminology management, presented at LREC 2014; the GitHub organisation above is its implementation.
- **Linguoc LexTerm** (Universitat Oberta de Catalunya, 2007): a free tool for the statistical extraction of
  terminology from text, distributed as Perl source and a Windows program. It appears dormant.
- **"LexTerm" as the name of a method** (Translating and the Computer 28, 2006) for carrying dictionary data
  over to concept-oriented terminology.

Neighbouring marks:

- **FlexTerm**, EU word and figurative mark, registered, classes 9 and 42. Class 9 is claimed by its whole
  heading and names software; class 42 names the design and development of software. It differs from "lexterm"
  by its first letter. This is the neighbour to look at in the second stage.
- **LEXTER**, EU word mark, registered, classes 1, 2 and 17 (chemicals, plastics): another field. A German mark
  LEXTER is registered as well; its list of goods was not read.
- **FLEXITERM**, EU word mark, class 9 (passive electronic components): another field.
- From TMview, alive: **FLEXTERM** in the United States (class 9) and Canada (class 36); **NexTerm**, EU and
  United Kingdom, classes 35, 39 and 42; **Lexters**, EU, class 45 (legal services); **LEXTERMAT**, France,
  class 2. Lapsed or ended: LEXITERM (France, classes 9 and 16), LEXTEAM, Luxterm and a number of FLEXTERM marks
  in other countries. "lextherm" brings up heating and insulation marks only (NEXTHERM, FLEXTHERM, EXTHERM).

## Assessment

"lexterm" is free as a package name and is not registered as a mark. It joins the two words of the field
(lexicon, terminology), so it is weak as a mark, and three research projects have used it before; the one that
still shows activity manages termbases for translators and lexicographers, not medical terms. The registered
mark FlexTerm in classes 9 and 42 is close in writing and sound; whether that matters depends on what the mark
is used for, which the register does not say. TMview adds no mark of the same name anywhere. The name was
chosen on 26 November 2026 with this known.

## The sibling: "lexident"

Proposed on the same day for the planned library of identifying information. First stage and three TMview
queries (fuzzy `lexident`, "contains" `lexident`, fuzzy `lexid`).

| Check | Result |
|---|---|
| Packages | `lexident` is free on PyPI, npm and crates.io |
| Domains | `.com` registered on 13 February 2026, no site seen; `.de`, `.org`, `.net`, `.eu`, `.io` without name servers |
| GitHub | no repository of that name |
| Web | no product of that name; "LexIdent" is the name of a function in two Go packages |
| DPMAregister | no mark "lexident"; FLEXIDENT (international, protection granted) and marks that contain it |
| TMview | **LEXIDENT**, application in the United States filed in 2026, class 10 (medical and dental apparatus); fuzzy search 36 entries |

What stands against the name:

- An application for the **identical word** is pending in the United States, in class 10. Software is in
  classes 9 and 42, so the goods differ; the word does not.
- "-dent" reads as dental. Almost every neighbour is a dental or oral-care mark: BEXIDENT (EU, classes 3 and
  5, and many countries), FLEXIDENT (several countries, classes 9, 10, 36, 44), LUXIDENT, TEXIDENT, Plexident.
- **LEXID** is registered in many offices (EU classes 35 and 42; United Kingdom, United States, China, India,
  Brazil, France), and a product of that name links the records of one person and is offered for health care
  as well. Whose marks they are was not read. "lexident" contains the word and names software about
  identifying people.

A name checked the same way as a fallback, first stage only: **identlex** is free on PyPI, npm and crates.io,
has no domain under `.com`, `.de`, `.org`, `.net`, `.eu`, `.io` or `.app`, no repository on GitHub, no hit on
the web and none in the DPMAregister. TMview was not asked.

## Candidates looked at before

Checked the same way on the same day:

- **termilex**: rejected. Termlex Ltd (United Kingdom) offers terminology and clinical-coding tools for SNOMED CT
  and FHIR and is listed in SNOMED International's marketplace.
- **termiscope**: free as a package and without a mark, but `termiscope.com` belongs to a pest-control firm of
  that name (United States, since August 2026), and a terminal tool of the same name is on GitHub.
- **lemmamed**: free everywhere checked; nearest names "Lema Med" (an occupational-health service in Bulgaria)
  and the EU marks "Lemma" (class 35) and "LEMMA-X" (classes 36, 42 and 45, payments).
- **glossema**: free in packages and domains; two small unrelated projects on GitHub.
- Rejected early: glossdoc (a car-care shop), medgloss (an existing medical glossary project), medlemma
  (Swedish for "member"), termdoc, termscope and termlens (taken packages, terminal tools), glossator (domains
  and npm taken), nomenscope (free, but "nomen" stands for personal names in the neighbouring projects).
